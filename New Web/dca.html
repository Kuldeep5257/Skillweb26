Course Overview

What this course is designed to teach

A Diploma in Computer Applications pathway covering core computer skills, Office tools, Excel, internet, and practical workplace applications. The curriculum below is organized as an easy-to-update outline. Exact module order, batch duration and included software can be confirmed with the academy before admission.
