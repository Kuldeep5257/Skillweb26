Build confidence with everyday computer use, MS Office, internet tools, file management, and digital productivity. The curriculum below is organized as an easy-to-update outline. Exact module order, batch duration and included software can be confirmed with the academy before admission.

Learning Outcomes

By the end of the program, you should be able to

  • ✓Use a Windows computer confidently for everyday work and study.
  • ✓Create clean documents, spreadsheets and presentations.
  • ✓Manage files and folders in an organized way.
  • ✓Use email, web search and common online services safely.
  • ✓Handle basic office and data-entry tasks with greater speed and confidence.
