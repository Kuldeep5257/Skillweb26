Course Overview

What this course is designed to teach

Career-focused analytics training with Advanced Excel, Power Query, SQL/PostgreSQL, Power BI, Python, Gen-AI, projects, portfolio work, and interview preparation. The curriculum below is organized as an easy-to-update outline. Exact module order, batch duration and included software can be confirmed with the academy before admission.

Syllabus Highlights

What you will study

✓
Advanced Excel

Data cleaning, formulas, functions, PivotTables, charts and analytical reporting.

✓
Power Query

Import, transform, combine and prepare data for analysis.

✓
SQL / PostgreSQL

Queries, filters, joins, aggregations, subqueries and relational data analysis.

✓
Power BI

Data models, DAX foundations, interactive dashboards and business reporting.

✓
Python for Analytics

Python foundations, data manipulation, analysis and visualization workflows.

✓
Gen-AI for Analysts

Practical AI-assisted analysis, prompting and productivity workflows.

✓
Portfolio Projects

Hands-on projects designed to demonstrate practical analytics skills.

✓
Interview Preparation

Resume/portfolio guidance, common interview topics and practical preparation.

Learning Outcomes

By the end of the program, you should be able to

  • ✓Clean, structure and analyze datasets using multiple industry tools.
  • ✓Write SQL queries to answer practical business questions.
  • ✓Build clear dashboards and reports in Power BI.
  • ✓Use Python for foundational data analysis tasks.
  • ✓Create portfolio projects that demonstrate end-to-end analytical thinking.
  • ✓Prepare more confidently for entry-level data analytics interviews.
